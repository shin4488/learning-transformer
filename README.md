# ゼロから理解するTransformer — 基礎から学ぶLLMの仕組み

本書は、ChatGPTなどの大規模言語モデル（LLM）の中核技術である **Transformer** の仕組みを、数学や機械学習の専門的な前提知識がなくても理解できるように解説したテキストです。

---

## 本書の特徴

多くの解説では省略されがちな「前提となる数学や基礎理論」から丁寧に紐解き、無理なくステップアップできる構成にしています。

- **段階的なアプローチ**: ベクトル、行列、微分、確率などの数学の基礎から順を追って解説します。
- **直感的な理解**: すべての数式に日本語による意味付けと、具体的な手計算の例を掲載しています。
- **視覚的な解説**: 構造やデータの流れを Mermaid による図解やフローチャートで整理しています。

---

## 読み進め方の目安

- **初学者の方**: 第1章から順に読み進めることを推奨します。各章で登場する概念が以降の章の土台となります。
- **数学（線形代数・微積分）の基礎がある方**: 第1〜3章を軽く確認した上で、第4章（機械学習の基礎）または第6章（言語の数値化）から進めることができます。
- **Attention機構を重点的に学びたい方**: 第8章・第9章がTransformerの核心部です。必要に応じて第2章（内積）や第5章（Softmax）を参照してください。
